
## 🌾 Krishi – Smart Farming Assistant
**Krishi** is a smart agriculture companion app designed to empower farmers by providing real-time, sensor-based insights from their fields. It uses IoT technology and modern APIs to deliver crucial data that helps optimize farming practices, reduce waste, and boost crop yields. Whether you're a small-scale farmer or managing large fields, KrishiV2 brings precision farming to your fingertips.


---

### 📱 Key Features:
- 📡 Live Sensor Data
Real-time monitoring of soil moisture, temperature, humidity, and other environmental parameters using ESP32 and field sensors.
- **🌱 Crop Recommendation System**
Suggests the most suitable crops based on soil condition, NPK values, and real-time sensor inputs.
-  **🧮 NPK Calculator**
Calculates Nitrogen, Phosphorus, and Potassium requirements based on soil condition to ensure balanced nutrition.
-  ** 🧠 Smart Farming Insights**
AI-driven recommendations for irrigation, fertilization, and pest control.
-  **💰 Expense Tracker**
Helps farmers manage and track their day-to-day farming expenses, providing financial awareness and control.
-  **🌍 Weather Forecasting**
Integrated Weather API provides hyperlocal forecasts to help plan farming activities more efficiently.
-  **🔔 Alerts & Notifications**
Get notified when sensor values cross thresholds (e.g., low moisture, high heat).
-  **🗞️ Live Farming News**
Stay updated with the latest news, updates, and schemes relevant to agriculture and rural development.
-  **🗺️ Smart Field Maps**
Visual representation of fields and sensor locations using the Google Maps API.
-  **🛒 Live Market Data**
Access real-time prices of crops and commodities in nearby markets to make better selling decisions.
-  **📊 Data Visualization**
Intuitive graphs and visuals to help farmers understand trends and insights easily.

---

### 🛠️ Built With:
- Flutter – Cross-platform UI framework for beautiful mobile interfaces.
- Firebase – Real-time database, authentication, and notifications.
- Google Maps API – To visualize field data and sensor locations.
- Weather API – For providing up-to-date weather insights.
- ESP32 / Arduino Sensors – For real-time environmental monitoring.
- LoRa/NodeMCU – For long-range data transmission in remote areas (optional setup).
